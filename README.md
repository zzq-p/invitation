# 人工智能学院 2027 届毕业典礼 · 邀请函小程序

一款可直接导入 **微信开发者工具** 运行的原生微信小程序邀请函，适用于**教师、2027 届毕业生、往届校友、家长及来宾**等群体。

- 风格：夜幕靛蓝 × 仪式鎏金，星空粒子 + 神经网络连线动画，贴合人工智能学院特色
- 无需服务器、无需任何外部图片或网络资源，所有数据保存在本机缓存
- 仅需修改 **`config.js` 一个文件**，即可替换为学院正式信息

---

## 一、页面结构

| 页面 | 路径 | 功能 |
| --- | --- | --- |
| 封面页 | `pages/cover/cover` | 星空粒子动画、学院徽章、烫金标题、「敬启邀请函」 |
| 邀请函主页 | `pages/home/home` | 正式请柬正文、时间地点、实时倒计时、典礼流程时间轴、交通指引、温馨提示 |
| 出席确认页 | `pages/rsvp/rsvp` | 身份选择（教师/毕业生/校友/家长）、信息填写、生成**电子席位纪念票**（含副券条码） |
| 祝福寄语墙 | `pages/wishes/wishes` | 书写并展示毕业寄语，双列便签墙，预置学院寄语 |

## 二、导入微信开发者工具（保姆级步骤）

1. 打开桌面版 **微信开发者工具**（若未安装，前往 https://developers.weixin.qq.com/miniprogram/dev/devtools/download.html 下载「稳定版 Stable Build」并安装）。
2. 登录后，在首页点击左上角 **「+」号 →「小程序」→「导入项目」**。
3. 「项目目录」点击「选择」，选中本文件夹 **`invitation`**（即包含 `app.js`、`project.config.json` 的这一层）。
4. 「AppID」处：
   - 仅预览 / 内部使用 → 保持默认的 **`touristappid`（游客模式 / 测试号）** 即可，直接点「导入」；
   - 若学院已有正式小程序 AppID → 填入正式 AppID（替换方法见下方第五节）。
5. 点击「导入」，稍等片刻即可在左侧模拟器看到封面，点击「敬启邀请函」即可浏览全部内容。
6. 想在手机上查看：点击工具栏 **「预览」**，用微信扫码即可（游客模式下部分预览功能受限，属正常现象）。

> 提示：模拟器顶部可切换机型（如 iPhone 15、华为 Mate 60），建议各切换一次检查适配效果。

## 三、修改邀请函信息（只需改 `config.js`）

用微信开发者工具左侧文件树打开根目录的 **`config.js`**，按下表修改后保存（快捷键 `Ctrl + S`），模拟器会自动刷新：

| 配置项 | 含义 | 示例 |
| --- | --- | --- |
| `schoolName` | 学校全称 | `'某某大学'` |
| `collegeName` | 学院名称 | `'人工智能学院'` |
| `grade` | 届别 | `'2027届'` |
| `ceremonyName` | 典礼全称 | `'毕业典礼暨学位授予仪式'` |
| `ceremonyDate` | **倒计时用**时间，格式 `YYYY-MM-DDTHH:mm:ss+08:00`，请勿改动格式 | `'2027-06-26T09:00:00+08:00'` |
| `ceremonyTimeText` | 页面展示的时间文字，可自由书写 | `'二〇二七年六月二十六日（星期六）上午 9:00'` |
| `lunarDate` | 农历日期（可选） | `'农历五月廿二'` |
| `venue` | 场馆名称 | `'学校大礼堂'` |
| `address` | 详细地址 | `'江西省南昌市某某区某某路 1 号'` |
| `schedule` | 典礼流程数组，可增删，每项含 `time / title / desc` | 见文件内示例 |
| `tips` | 温馨提示数组 | 见文件内示例 |
| `traffic` | 交通指引数组，含 `icon / title / desc` | 见文件内示例 |
| `presetWishes` | 祝福墙预置寄语，含 `name / role / text` | 见文件内示例 |

> 注意：所有文字都必须用**单引号**包裹，字符串内部如需换行请保持在同一行；流程数组增删时，各条目之间的逗号不要遗漏。

## 四、添加背景音乐（可选）

1. 在项目根目录新建文件夹 `audio`，放入背景音乐，命名为 `bgm.mp3`（小程序支持 mp3 / m4a / aac）。
2. 打开 `config.js`，将最后一项改为：
   ```js
   bgmSrc: '/audio/bgm.mp3'
   ```
3. 保存后，封面右下角、内页右上角会出现音乐按钮，点击即可播放 / 暂停。
4. 保持 `bgmSrc: ''`（空字符串）则不显示音乐按钮、不播放任何声音。

## 五、替换为正式 AppID 与发布

1. 用学院主体在微信公众平台（https://mp.weixin.qq.com）注册小程序，在「开发 → 开发管理 → 开发设置」查看 **AppID**。
2. 微信开发者工具右上角点击「详情 → 基本信息」，或直接打开 `project.config.json`，将
   `"appid": "touristappid"` 中的值替换为正式 AppID。
3. 确认 `config.js` 中所有信息为正式内容后，点击工具栏 **「上传」**，填写版本号（如 `1.0.0`）与备注。
4. 登录微信公众平台，在「管理 → 版本管理」中将上传的版本提交审核，审核通过后「发布」。
5. 发布后可将小程序卡片 / 二维码转发到教师群、班级群、校友群，或嵌入公众号推文。

## 六、数据与隐私说明

- 出席确认与寄语均通过 `wx.setStorageSync` 保存在**使用者本机微信缓存**中，不经过任何服务器，卸载小程序或清除缓存后数据会清空。
- 如需统一汇总全院出席信息，需要另行接入云开发（微信云开发数据库）或自建后端，可在本项目基础上扩展。

## 七、常见问题

**Q：导入后提示「未找到 app.json」？**
A：导入目录选错了，应选择包含 `app.js`、`app.json` 的 `invitation` 文件夹本身，而不是它的上一级。

**Q：封面是黑屏 / 没有动画？**
A：点击「详情 → 本地设置」，确认「将 JS 编译成 ES5」「增强编译」已开启；或点击工具栏「编译」旁的下拉，选择「清缓存 → 全部清除后重新编译」。

**Q：倒计时数字不动？**
A：检查 `config.js` 中 `ceremonyDate` 是否严格保持 `YYYY-MM-DDTHH:mm:ss+08:00` 格式。

**Q：emoji 表情显示成方框？**
A：开发者工具模拟器字体问题，真机上可正常显示；也可将 `traffic` 等处的 emoji 替换为本地图标。

**Q：如何修改主题颜色？**
A：打开 `app.wxss`，顶部 `page { ... }` 中以 `--gold` 开头的变量即鎏金色值，统一调整即可。
